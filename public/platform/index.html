How it works

From scattered listings to usable data.

Four steps. Less reading — more of the pipeline.

1

Verified venues

Start from a vetted venue list — real places with addresses and coordinates.

2

Continuous ingestion

Pull from ticketing feeds and venue calendars into one pipeline.

3

Normalize & fill gaps

Clean messy fields, resolve venues, structure dates, categories, and links.

4

Serve to your product

Deliver structured events to apps, newsletters, agents, BI — or browse on the web.

Plug in FindLocal

Plug in FindLocal in a few minutes.

Three paths — pick the client you already use.

Claude · Connectors 
https://findlocal-mcp.elliot-fdd.workers.dev/mcp
  1. 1Open Claude and go to Connectors.
  2. 2Paste this MCP URL: https://findlocal-mcp.elliot-fdd.workers.dev/mcp
  3. 3While searching, confirm the FindLocal connector toggle is on.
  4. 4Ask what’s happening nearby.
~/.cursor/mcp.json 
{
  "mcpServers": {
    "findlocal": {
      "url": "https://findlocal-mcp.elliot-fdd.workers.dev/mcp"
    }
  }
}
  1. 1Add the server block above to your Cursor MCP config.
  2. 2Restart Cursor (or reload MCP servers).
  3. 3Ask your agent about local events.
terminal 
# add the remote MCP server
claude mcp add --transport http findlocal \
  https://findlocal-mcp.elliot-fdd.workers.dev/mcp
  1. 1Run the command above in your terminal.
  2. 2Start a session and ask about upcoming local events.
